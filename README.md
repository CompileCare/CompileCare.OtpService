# HeapCare OTP Service

OTP delivery and verification service for the HeapCare healthcare platform.

> **Brand migration in progress:** HeapCare is the product brand. Repository names, source namespaces, package IDs, database identifiers, OIDC realm/client IDs, and deployment identifiers remain unchanged until their coordinated migration is implemented and validated.

This repository is currently a minimal scaffold. Implementation scope, provider selection, delivery guarantees, abuse controls, audit requirements and operational runbooks must be established before production use.
